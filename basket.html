Basket (0)

[under construction — not yet built]

The Basket is planned as a way to collect fragments while moving through the garden — a bed, a field note, a dictionary entry — and carry them somewhere for later reading.

This first prototype does not implement it. A working basket needs to remember what you've collected as you move between pages, which this site can only do with JavaScript as a hard dependency — a deviation from how everything else here is built, where JavaScript only ever enhances content that already works without it. "Basket (0)" elsewhere on the site is static text, not a live count.
